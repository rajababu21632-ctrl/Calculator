# 🧮 MCA Scientific Calculator

A modern and responsive **Scientific Calculator Web Application** developed as an MCA GENERAL academic project using **HTML, CSS, JavaScript, and Python Flask**.

The application provides basic arithmetic operations and advanced scientific functions through a clean, user-friendly interface.

## 🚀 Features

- Basic arithmetic operations: Addition, Subtraction, Multiplication and Division
- Scientific functions: Sin, Cos, Tan, Square Root
- Logarithmic functions: Log and Natural Log (ln)
- Mathematical constants: Pi (π) and Euler's Number (e)
- Power and Factorial calculations
- Percentage calculations
- DEG and RAD angle modes
- Previous answer (Ans) functionality
- Clear (AC) and Delete (DEL) buttons
- Keyboard support for calculations
- Responsive user interface
- Flask-powered local web server

## ⚙️ Installation and Setup

Follow these steps to run the project on your computer.

### 1. Clone the Repository
https://github.com/rajababu21632-ctrl/Calculator/edit/main/README.md
```

### 2. Open the Project Folder

```bash
cd MCA-Scientific-Calculator
```

### 3. Install Flask

```bash
python -m pip install flask
```

### 4. Run the Application

```bash
python app.py
```

### 5. Open in Browser

After running the application, open the following URL:

```text
http://127.0.0.1:5000
```

The Scientific Calculator will open in your web browser.
